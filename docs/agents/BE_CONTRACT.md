## Response Envelope

All endpoints return:
```json
{
  "success": true|false,
  "code": "SUCCESS_CODE|ERROR_CODE",
  "message": "Human-readable message (English)",
  "data": { ... } | null,
  "timestamp": "2026-03-25T10:00:00Z"
}
```

Paginated responses wrap data in `PageResponse`:
```json
{
  "content": [...],
  "page": 0,
  "size": 20,
  "totalElements": 100,
  "totalPages": 5,
  "hasNext": true,
  "hasPrevious": false
}
```

## 1. Auth Module

**Base:** `/vietrecruit/auth`

| Method | Path | Description | Request Body | Response Data | Auth | Rate Limited |
|--------|------|-------------|-------------|---------------|------|-------------|
| POST | `/login` | Email + password login | `LoginRequest{email, password}` | `LoginResponse{accessToken, refreshToken, expiresIn, tokenType}` | No | Yes |
| POST | `/register` | New account registration | `RegisterRequest{email, password, fullName, phone, accountType[CANDIDATE|EMPLOYER]}` | void (201) | No | Yes |
| POST | `/register/invite` | Register via invitation token | `RegisterByInviteRequest{token, password, fullName, phone}` | void (201) | No | Yes |
| POST | `/refresh` | Refresh access token | `RefreshTokenRequest{refreshToken}` | `LoginResponse` | No | Yes |
| POST | `/logout` | Invalidate tokens | `RefreshTokenRequest{refreshToken}` | void | Yes | No |
| POST | `/forgot-password` | Send password reset email | `ForgotPasswordRequest{email}` | void | No | Yes |
| POST | `/reset-password` | Reset password with token | `ResetPasswordRequest{token, newPassword}` | void | No | Yes |
| POST | `/change-password` | Change current password | `ChangePasswordRequest{currentPassword, newPassword}` | void | Yes | No |
| POST | `/verify-otp` | Verify email OTP | `VerifyOtpRequest{email, otp}` | void | No | Yes |
| POST | `/resend-otp` | Resend OTP email | `ResendOtpRequest{email}` | void | No | Yes |
| POST | `/oauth2/exchange` | Exchange OAuth2 auth code | `OAuth2ExchangeRequest{provider, code, state}` | `LoginResponse` | No | No |

**JWT Claims (generated by `JwtService.generateAccessToken()`):**
- `sub` (String): userId (UUID)
- `roles` (String[]): role codes (e.g., `["COMPANY_ADMIN"]`)
- `email_verified` (boolean): email verification status
- `jti` (String): random UUID (token ID)
- **NOT included:** companyId, email, fullName, companyProfileComplete, avatarUrl, permissions

## 14. FE-BE Contract Gaps

| Gap | Severity | Description |
|-----|----------|-------------|
| Missing `POST /companies` | CRITICAL | No way to create a company for new employers (BUG-005) |
| JWT missing claims | HIGH | JWT lacks companyId, email, fullName, companyProfileComplete -- FE parses phantom claims |
| LoginResponse missing user | HIGH | LoginResponse only has tokens, no user object -- FE has to parse JWT |
| Error code format mismatch | HIGH | FE maps `AUTH_001`-`AUTH_006`, BE sends `AUTH_INVALID_CREDENTIALS` etc. (BUG-004) |
| Enum spelling: CANCELED vs CANCELLED | MEDIUM | BE interview_status uses `CANCELED`, FE uses `CANCELLED` |
| FE phantom enum values | MEDIUM | FE has `JOB_STATUS.EXPIRED`, `INTERVIEW_STATUS.NO_SHOW`, `OFFER_STATUS.EXPIRED`, `USER_ROLES.EMPLOYER` -- none exist in BE |
| No `GET /users/me` in auth flow | MEDIUM | After login, FE has no way to fetch full user context (relies on incomplete JWT) |
| Permissions claim missing | LOW | FE router checks JWT `permissions` array that BE never includes |
